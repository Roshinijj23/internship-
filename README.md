This repository contains a Website Improvement Analysis of the InAmigos Foundation website.
The project focuses on identifying issues related to UI design, layout, content, navigation, user experience, and functionality, and suggests improvements based on usability and professional web standards.
The analysis includes:
Homepage UI and color scheme improvements
Identification of non-functional buttons and broken links
Expected behavior of pages such as Join Us, View All Causes, Events, Gallery, and Donation
User experience and accessibility observations
Screenshots with annotations and clear improvement suggestions
This work was completed as part of an internship task to develop practical skills in website analysis, UX thinking, and usability evaluation.
